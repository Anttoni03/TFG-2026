# TFG-2026
Repositorio consistente en la documentación y anexos resultantes de mi TFG con la UIB APLICACIÓN DE TÉCNICAS DE INTELIGENCIA ARTIFICIAL PARA EL CUIDADO DE COLMENAS, DETECCIÓN DE AMENAZAS Y PLAGAS

El proyecto implementa un sistema de detección de objetos basado
en YOLO para la identificación de Vespa orientalis y Apis mellifera,
incluyendo inferencia convencional y mediante SAHI.

## Versionados
Python 3.11.14 | packaged by Anaconda, Inc. | (main, Oct 21 2025, 18:30:03) [MSC v.1929 64 bit (AMD64)]
PyTorch 2.9.1+cu128
CUDA 12.8
OpenCV 4.11.0

Dentro de la memoria se encuentran los pesos del modelo M4 en formato .pt, listos para ser usados.

Configurado el entorno virtual como Miniconda en el equipo, se podrá importar el fichero GuiaTest.ipynb para probar el modelo resultante
